## 字体与封面的可验证边界

Nirmala UI 不含中文字形。经用户允许, 中文阅读性优先于复制拉丁细体的字重: 中文正文与表格统一使用 Microsoft YaHei 常规体, 标题使用 Microsoft YaHei Bold。相比上一版 Light, 常规体笔画更清晰, 适合屏幕阅读, 同时保留原版无衬线的风格。英文、数字和原有音乐记号沿用原书对应字体。字号、基线和页边距仍采用原始数值。

正文的字号、坐标、基线和图像几何可以客观验证; 中文字形不可能与不含中文的原字体相同。中英字宽不同, 也不强行逐字对齐。

封面文字已烘焙进位图, 没有字体对象与字号可读。中文主标题采用 76 pt 粗体, 副标题采用 32 pt 粗体, 用 72 DPI 校样匹配原字面高度。主标题两行的可见纵向范围对齐原书约 y=78–150 和 y=169–241 pt。这是按可见结果匹配的中文参数, 并非声称恢复了原封面的字体字号。

## 验证

构建先依据 `translation/source.json` 检查原书哈希和页数, 再从原书实时提取布局并检查译文覆盖率。各文字区域必须能按原字号排入, 否则失败, 不静默漏译或自动缩字。验证器独立重读原书与输出, 比较图像、页面几何、链接、矢量路径, 检查输出实际字号与坐标, 并提取输出文字核对排版记录。大型布局转储只在需要检查时生成到 `build/`, 不纳入版本控制。

渲染检查覆盖 93 页总览校样, 并放大检查封面、目录、正文、表格、网址、谱例与最后一章。本次重译与校订已完成; 机器验证不能替代母语读者的终审。

当前采用原位排版。未来若有必须增页的译文, 需要另行实现分页、图片锚定与目录重算, 不能靠缩字或覆盖图片处理。
